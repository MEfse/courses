### Описание проекта

Данный проект посвящён задаче определения тональности текста (sentiment analysis).
Цель — автоматически классифицировать текстовые сообщения по эмоциональной окраске (положительная / отрицательная) с использованием различных подходов обработки текста и моделей машинного обучения.

В рамках проекта были последовательно реализованы и сравнены:

* классические ML-подходы,

* word-эмбеддинги (Word2Vec, GloVe),

* рекуррентные нейронные сети (GRU / LSTM),

* трансформерная модель BERT.

## Постановка задачи

* Тип задачи: бинарная классификация текста
* Вход: текстовое сообщение
* Выход: метка тональности (0 — отрицательная, 1 — положительная)

Для оценки качества использовались стандартные метрики классификации:

* accuracy

* precision

* recall

* F1-score (macro и weighted)

## 1. Baseline

В качестве базового решения был реализован простой подход с классическими признаками и линейной моделью классификации.

Результат:

* accuracy ≈ 0.93

* macro / weighted F1 ≈ 0.93

Baseline показал стабильное и достаточно высокое качество, став отправной точкой для дальнейших улучшений.

## 2. Word2Vec и GloVe

Далее были протестированы векторные представления слов:

* Word2Vec

* GloVe

Эмбеддинги агрегировались на уровне текста (усреднение векторов) и подавались в классическую модель классификации.

Результат:
Метрики полностью совпали с baseline.

**Вывод:**
Использование word-эмбеддингов не дало прироста качества при простой агрегации и линейной модели. Вероятно, семантическая информация теряется без учёта порядка слов.

## 3. GRU / LSTM поверх эмбеддингов

Для учёта последовательной структуры текста были обучены рекуррентные нейронные сети (GRU / LSTM) поверх эмбеддингов.

Результат:

* accuracy ≈ 0.94

* weighted F1 ≈ 0.94

улучшен recall для положительного класса

**Вывод:**
Рекуррентные модели позволили эффективно использовать эмбеддинги за счёт учёта порядка слов и контекста, что привело к измеримому улучшению качества.

## 4. BERT

На финальном этапе была обучена трансформерная модель BERT с fine-tuning под задачу классификации.

Результат:

* accuracy ≈ 0.93

* F1 ≈ 0.93

**Вывод:**
Несмотря на более сложную архитектуру, BERT не превзошёл GRU/LSTM и показал качество на уровне baseline. Для данной задачи и объёма данных применение трансформера оказалось избыточным.

## Итоговое сравнение моделей

| Модель                         | Accuracy | Weighted F1 |
|--------------------------------|----------|-------------|
| Baseline                       | 0.93     | 0.93        |
| Word2Vec + ML                  | 0.93     | 0.93        |
| GloVe + ML                     | 0.93     | 0.93        |
| **GRU / LSTM + Embeddings**    | **0.94** | **0.94**    |
| BERT                           | 0.93     | 0.93        |

## Основные выводы

* Простые линейные модели уже дают сильный baseline.

* Word-эмбеддинги неэффективны без моделей, учитывающих порядок слов.

* GRU / LSTM обеспечивают наилучший баланс между сложностью и качеством.

* BERT не всегда гарантирует прирост и требует обоснования с точки зрения данных и ресурсов.
