# Классификация Мошенничества по Транзакциям с Кредитными Картами

## Описание

Целью данного проекта является создание модели машинного обучения для распознавания мошеннических транзакций по кредитным картам. Модели классификации обучаются на наборе данных, содержащем информацию о транзакциях, совершённых европейскими держателями карт в сентябре 2013 года. Задача заключается в предсказании, является ли транзакция мошенничеством или нет.

### Контекст

Важно, чтобы компании, выпускающие кредитные карты, могли эффективно распознавать мошеннические транзакции, чтобы предотвратить несанкционированные расходы для клиентов. В рамках этого проекта разработаны несколько моделей для решения задачи бинарной классификации.

## Набор Данных

Набор данных содержит информацию о транзакциях, совершённых по кредитным картам в сентябре 2013 года. Всего в наборе 284,807 транзакций, из которых только 492 являются мошенническими, что делает задачу крайне **несбалансированной**.

- **Особенности данных**:
  - Признаки: 28 главных компонент, полученных с помощью метода **PCA**.
  - Признаки «Время» и «Сумма» не были преобразованы с помощью PCA. Признак «Время» указывает количество секунд с момента первой транзакции, а признак «Сумма» содержит сумму транзакции.
  - **Целевая переменная** (класс): принимает значение `1`, если транзакция является мошеннической, и `0` — если нет.

Поскольку данные несбалансированы, для оценки моделей используется **AUPRC (площадь под кривой точность-полнота)** вместо традиционной точности.

## Improvements

При использовании более сложных моделей в отличие от baseline, которые могут улавливать нелинейность, отказ от SMOTE и удаления не нужнных фичей после feature importance получили прирост метрики f1-score с 0.12 до 0.88 (разинца составляет 0.76)

## Используемые Модели

### 1. **Модель Dummy**
Модель **Dummy** предсказывает только один класс (например, только нормальные транзакции), что дает идеальный результат по точности, но абсолютно не подходит для классификации мошенничества.

- **Результаты**:
  - **Accuracy**: 1.0 (предсказание только одного класса)
  - **Recall**: 0.0 (невозможность обнаружения мошенничества)
  - **Precision**: 0.0
  - **F1 score**: 0.0

### 2. **Логистическая Регрессия**
Логистическая регрессия показала немного лучшие результаты, чем Dummy модель, но всё равно результаты остаются близкими к случайным.

- **Результаты**:
  - **Accuracy**: 0.51
  - **Recall**: 0.64 (модель находит часть мошеннических транзакций)
  - **Precision**: 0.00 (не может точно классифицировать мошеннические транзакции)
  - **F1 score**: 0.00

### 3. **XGBoost**
XGBoost — модель, продемонстрировавшая лучшие результаты по скорости обучения и качеству классификации для дисбалансированных данных.

- **Лучшие параметры**:
  - `learning_rate=0.19`
  - `max_depth=5`
  - `n_estimators=1785`
  - `alpha=0.15`
  - `gamma=0.58`
  - `lambda=0.86`
- **Результаты**:
  - **Accuracy**: 1.00
  - **Recall**: 0.81
  - **Precision**: 0.91
  - **F1 score**: 0.85
  - **Macro Average**:
    - **Precision**: 0.95
    - **Recall**: 0.90
    - **F1 score**: 0.93

### 4. **LightGBM**
LightGBM также показал хорошие результаты, с небольшой потерей в точности по сравнению с XGBoost.

- **Результаты**:
  - **Accuracy**: 1.00
  - **Recall**: 0.80
  - **Precision**: 0.89
  - **F1 score**: 0.84
  - **Macro Average**:
    - **Precision**: 0.94
    - **Recall**: 0.90
    - **F1 score**: 0.92

### 5. **CatBoost**
CatBoost продемонстрировал самые низкие результаты для класса 1 (мошенничество) в сравнении с другими моделями.

- **Результаты**:
  - **Accuracy**: 1.00
  - **Recall**: 0.81
  - **Precision**: 0.77
  - **F1 score**: 0.79
  - **Macro Average**:
    - **Precision**: 0.89
    - **Recall**: 0.90
    - **F1 score**: 0.89

## Заключение

1. **Модель Dummy** показала идеальную точность, но не смогла обнаружить мошенничество. Это подтверждает, что высокая точность не всегда означает хорошую модель, особенно при дисбалансированных данных.
2. **Логистическая регрессия** немного улучшила результаты, обнаружив часть мошенничества, но всё ещё не смогла точно классифицировать мошеннические транзакции.
3. **XGBoost** продемонстрировал лучшие результаты по **точности**, **recall** и **F1 score**, что делает его отличным выбором для данной задачи. Эта модель обучается быстрее и эффективнее всех.
4. **LightGBM** также показал хорошие результаты, хотя и немного уступает XGBoost по точности для класса мошенничества.
5. **CatBoost** оказался менее эффективен по сравнению с другими моделями, несмотря на хорошие результаты для класса 0.
